OrbitSim

Role: Graphics Programmer Stack: C++, OpenGL, ImGUI

Performance Optimization

Simulating thousands of bodies with gravitational interactions requires careful memory management. OrbitSim utilizes instanced rendering and spatial partitioning to maintain 60 FPS.

Features

  • Modular Pipeline: Custom graphics engine written in C++.
  • Physics Accuracy: Implements N-body gravitational simulations.
  • Interactive UI: Real-time parameter tuning using ImGUI.
