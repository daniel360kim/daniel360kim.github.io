project page / paper / poster

A photorealistic, differentiable drone simulator built from 3D Gaussian Splat reconstructions, used to train monocular RGB navigation policies across diverse scenes.

Ember: Rocket Active Control
project page / code

A custom Teensy-based flight computer and thrust vector control system that actively stabilizes model rockets during ascent, starting from PID control with Kalman filtering. Ember extends it with a differentiable 6-DOF rocket simulator that trains a neural TVC controller by backpropagating through the physics, then flies the learned policy on the real hardware.
